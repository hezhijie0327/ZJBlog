# 数据采集手册（travel-guide）

原则：**权威源优先**（12306 > OTA 票面 > 官网/官方海报 > 多平台攻略），所有价格与时刻记录"口径 + 核实日期"，文末注明"以出行当日官方公告为准"。

## 12306 余票/时刻（内部浏览器，权威源）

前提：加载 `browser-use:control-browser` 技能，操作 IAB 标签页。

1. 打开 `https://kyfw.12306.cn/otn/leftTicket/init?linktypeid=dc`（查询页，无需登录即可查余票）。
2. **取站名电报码**（不要凭记忆猜）：页面内执行
   ```js
   await fetch("https://kyfw.12306.cn/otn/resources/js/framework/station_name.js", { credentials: "include" })
   ```
   返回文本用 `@([^@|]+)\|([^@|]+)\|([A-Z]+)\|` 逐条解析（py|站名|电报码）。已核实：上海南 SNH、上海虹桥 AOH、上海松江 IMH、义乌 YWH、横店 HJU、金华 JBH。
3. **填查询条件**：每站有两个输入框——文本框 `#fromStationText` / `#toStationText` 和隐藏码框 `#fromStation` / `#toStation`，**两个都要写值**并派发 `change` + `blur` 事件；日期 `#train_date`（`YYYY-MM-DD`）。
   - ⚠️ Playwright 的 `click()` 在此页会因可操作性检查超时——查询按钮 `#query_ticket` 直接在 `evaluate` 里 DOM `.click()`。
4. **读结果**：表格 `#queryLeftTable`，每行 `tr` 内 `a.number` 是车次；td 依次为 出发/到达站、出发/到达时间、历时、各席别余票，末列为备注。多终到车次（如一场车停上海南+上海虹桥）会出现多行，按用户指定车站过滤。
5. **起售语义**：备注"N点起售" = 该出发车站在**当日 N:00** 放票（跨 天车票开售首日常见，如 9/22 查 10/6 全部显示"12点起售"）；此时无余票数据，攻略应写"X 日 N:00 准点抢"。已售罄显示"候补"。
6. 想要精确票价：点行内"查看票价"弹层，或用用户提供的实付价（实付常低于票面价，如折扣票）。

## OTA 门票详情页（携程 m.ctrip.com 等）

用浏览器打开用户给的分享链接，等 JS 渲染后 `domSnapshot()`，重点提取：

- **费用包含**：园区/场馆清单、"赠送"项（如 赠送梦幻谷）。
- **有效期与限次**："仅限使用日期当天使用""每个园区限进 1 次""1 天有效（自然日）"——这些是排路线的**硬约束**（限进 1 次 = 不能二次入园，路线只能走单环；白天场演出和夜场演出同园时必须二选一）。
- **入园方式**：无需换票凭身份证 / 需换票；适用条件与限购。
- **详情页海报（多张轮播图）**常含：档期活动一览（名 + 日期区间）、南区/北区分区动线（哪些园相邻可步行）、各园必看演艺官方写法——全部直接吸收；演艺名以海报为准（例：「八旗马战」不是「八旗战马」；「梦外滩」可能已更名）。

## 多平台情报

- **小红书**：`WebSearch` 直接中文关键词搜索（可尝试 site:xiaohongshu.com，站内链接常需登录，搜索摘要即可用）；热点攻略/避坑/实测向内容多。
- **交叉核实**：知乎（长攻略）、Trip/Trip.com（门票与开放时间）、大众点评/携程（餐厅地址、营业时间、排队策略）、横店兔 hengdiantour.com（横店探班/追星专精）、官网（演出开园基准）。
- **餐厅**：记录 总店地址、营业时间、排队策略（"饭点排长队，X 点前到"）。
- **行李寄存**：车站常**无自助柜**，写"出站服务台走人工寄存处"；第三方小程序（途简单/存知己）给价格区间（行李箱约 ¥10-20/天）。
- **追星/探班类**：找本地专站与都市快报等媒体报道，标注"偶遇率高时段"。

## 用户实付信息回填

用户口述的订单（酒店 ¥X、门票 ¥Y、车票实付 ¥Z/人）是最优先数据：替换预估价、修正票面价口径（写"实付"），并重算 头部 💰 已落定支出 与第七节合计（两处必须相等）。已落定大项与待办预估项在预算表中用 ✅ / ⏳ 区分。
